# 常青动一动

为 70+ 长者设计的温和全身入门活动。无需登录，只保留一个正式入口：

https://modenl.github.io/workout/

## 2026-09 改版

- 21 个动作，7 个类别；按部位筛选、逐项预览、一键换组。
- 三维坐标绘制的轻量关节动画，区分正面/侧面，保持肢段长度；提供起止姿势对照。
- 竖屏跟练，方向和对照按钮置于画面外；文字、动画、控制按钮同屏。
- 唯一声音方案：Web Audio 播放内置 16 kHz 单声道 PCM 录音。无 TTS、无媒体播放器 fallback、无远程音频请求。
- 用户点击后启动声音；动画和语音共用音频时钟。每 4 拍完成一次，8 次后休息 20 秒，自动进入下一项。
- 可暂停、静音、延长休息；离开页面时暂停，结束后不会继续播放。
- 网站明确区分温和活动与足够负荷的力量训练，不宣称短短一组就满足全天/整周运动需求。

## 维护与验证

正式入口 `index.html` 是构建产物，包含全部样式、脚本和录音；无需服务器程序、数据库或 Sites。修改 `public/` 下的源文件，然后重新构建。仓库根目录的旧 `app.js`、`styles.css` 与 `audio/` 不被新版首页加载，保留以免破坏旧缓存。

使用 Node.js 22.13 或更新版本，不需要为静态构建安装依赖：

```sh
node --test tests/static-workout.test.mjs
node build/build-github-page.mjs index.html
```

预览构建后的首页，例如：

```sh
python3 -m http.server 8765
```

测试覆盖：21 个动作两侧与 5 个阶段的骨长、固定支撑点、随机方案覆盖、四拍录音数据、音频启动竞争条件、静音/暂停/恢复、自动休息/换项、单文件完整性。浏览器检查使用 360×640 和 390×844 竖屏尺寸；这不是小米真机扬声器测试。

声音测试按钮报告的是播放流程状态，不能判断用户是否实际听见。未经真机确认，不应宣称所有 Android 浏览器均已修好。GitHub 在中国不同网络中的可达性也不作保证。

发布时一次性提交最终首页和源文件，避免多个连续提交产生重复排队。提交后核对线上内容与构建文件，不通过不断增加 URL 来规避问题。

## 健康内容边界

依据 CDC 老年活动指南及 NHS 坐姿/力量练习编写，属于一般健康教育，不是个体化运动处方。近期手术、急性疼痛、站立不稳或有相关疾病者应先咨询专业人员；胸痛、明显气促或头晕时停止运动并按严重程度求医。
