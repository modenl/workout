# 常青动一动

为 40+ 中老年人设计的居家全身力量跟练：不需要器械和场地，分三档强度。无需登录，正式入口：

https://workout.postagi.co.uk/

由 Cloudflare Workers 托管（Worker 名 `workout`，配置见 `wrangler.jsonc`）。`main` 分支同时由 GitHub Pages 发布在 https://modenl.github.io/workout/ 。

## 三档强度

首页或动作库顶部选择练习强度（动作库的强度栏浏览时吸附在屏幕上方），今日计划、换一组和动作库都只从该档里选；切换后底部提示新的一组。选择和每档各自的计划都会本地记忆。首页示范图显示该档的代表动作。

- **40–55 岁 · 进阶**：徒手抗阻为主，如深蹲、后撤步蹲、靠墙滑蹲、扶桌俯卧撑、椅子臂屈伸、俯身划臂、站姿髋铰链、单腿提踵、单腿前倾平衡。
- **55–70 岁 · 标准**：站姿为主，扶稳练力量和平衡，也包含部分坐姿动作。
- **70+ · 温和**：坐姿和扶椅为主，即原有的 35 个动作。

一个动作可以属于多档（`public/library.js` 中每个动作的 `levels`）。共 51 个动作，每档的 7 个类别各至少 3 个可选。标准和进阶会用到一面空墙、一条毛巾和一张不会滑动的牢固桌子。

## 2026-09 改版

- 可选男、女示范人物，约 40 岁的成熟运动形象；首页与跟练页同步切换并本地记忆。共用关节骨架，不影响声音、节奏或动作。
- 动作库以卡片展示，按部位筛选当前强度的动作，或查看三档全部；整张卡片可点开预览。
- 三维坐标绘制的轻量关节动画，区分正面/侧面，保持肢段长度；提供起止姿势对照。
- 动作节奏采用最小加加速度（minimum-jerk）曲线：前两拍去、后两拍回，在起点和终点自然停稳。坐站起身先前倾到鼻尖过脚尖、双手扶大腿，再起身站直。
- 关节旁显示点线轨迹和方向箭头，指明这一拍往哪里去；合掌推压、毛巾拉开用推/拉箭头表示。起止姿势对照图同样标出轨迹。
- 肢体为带明暗的圆润造型：发力部位有柔和光晕，侧面远侧肢体稍暗，关节标记按前后遮挡绘制，脚离地时脚下阴影变淡。
- 休息倒计时期间循环预览下一个动作；换动作时画面淡入。
- 竖屏跟练，方向和对照按钮置于画面外；文字、动画、控制按钮同屏。
- 唯一声音方案：Web Audio 播放内置 16 kHz 单声道 PCM 录音。无 TTS、无媒体播放器 fallback、无远程音频请求。
- 在支持 Audio Session API 的浏览器中，创建和恢复音频前设置 `navigator.audioSession.type = "playback"`，避免 iOS 把数拍视为受静音模式影响的环境音。依据 [WebKit 官方问题记录](https://bugs.webkit.org/show_bug.cgi?id=237322)。不支持该 API 的浏览器继续使用同一 Web Audio 引擎；测试声音提示会显示当前模式。这不代表已通过 iPhone Air 真机出声验证。
- 用户点击后启动声音；动画和语音共用音频时钟。支持 `getOutputTimestamp` 的浏览器按扬声器实际播出的时间对齐动作与数拍，否则使用 `currentTime`。每 4 拍完成一次，8 次后休息 20 秒，自动进入下一项。
- 跟练动画按屏幕刷新率绘制（首页约 30 帧）；跟练中若持续掉帧，本次跟练改为稳定的约 30 帧。数拍录音在第 8 次结束时准时停止，休息前不会漏出下一轮的“一”。这一降级和音画对齐只在桌面 Chromium（含 CPU 降速模拟）中验证过，未经手机真机测试。
- 可暂停、静音、延长休息；离开页面时暂停，结束后不会继续播放。
- 网站明确区分温和活动与足够负荷的力量训练，不宣称短短一组就满足全天/整周运动需求。

## 维护与验证

正式入口 `index.html` 是构建产物，包含全部样式、脚本和录音；无需服务器程序、数据库或 Sites。修改 `public/` 下的源文件，然后重新构建。仓库根目录的旧 `app.js`、`styles.css` 与 `audio/` 不被新版首页加载，保留以免破坏旧缓存。

使用 Node.js 22.13 或更新版本，不需要为静态构建安装依赖：

```sh
node --test tests/static-workout.test.mjs
node build/build-github-page.mjs index.html
```

部署到 Cloudflare（构建到 `dist/cloudflare/` 后用 wrangler 上传，需本机已 `wrangler login`）：

```sh
npm run deploy
```

预览构建后的首页，例如：

```sh
python3 -m http.server 8765
```

测试覆盖：51 个动作两侧与 5 个阶段的骨长和脚不入地、每档每类至少 3 个动作、强度选择与各档计划记忆、男女人物渲染（绘图参数均为有限数值）、固定支撑点、固定肘部、动作节奏曲线、坐站起身顺序、轨迹箭头、扬声器时钟、数拍准时结束、箭头不出画面、休息预览、掉帧降级、随机方案覆盖、四拍录音数据、音频启动竞争条件、静音/暂停/恢复、自动休息/换项、单文件完整性。浏览器检查使用 360×640 和 390×844 竖屏尺寸；这不是小米真机扬声器测试。

声音测试按钮报告的是播放流程状态，不能判断用户是否实际听见。未经真机确认，不应宣称所有 Android 浏览器均已修好。GitHub 在中国不同网络中的可达性也不作保证。

发布时一次性提交最终首页和源文件，避免多个连续提交产生重复排队。提交后核对线上内容与构建文件，不通过不断增加 URL 来规避问题。

## 健康内容边界

依据 CDC 老年活动指南及 NHS 坐姿/力量练习编写，属于一般健康教育，不是个体化运动处方。近期手术、急性疼痛、站立不稳或有相关疾病者应先咨询专业人员；胸痛、明显气促或头晕时停止运动并按严重程度求医。

新增内容参考 [NHS 坐姿活动](https://www.nhs.uk/live-well/exercise/sitting-exercises/)、[NHS 力量练习](https://www.nhs.uk/live-well/exercise/strength-exercises/)及 [Royal Orthopaedic Hospital 的力量和平衡资料](https://roh.nhs.uk/services-information/therapy/otago-strength-and-balance-exercises)，采用空手、小幅度的活动变式。本站的四拍示范不是原版训练处方；展胸、前倾等活动不能视为足够负荷的增肌训练。扶稳动作必须使用不会滑动或倾倒的支撑，不能仅凭动画判断器材安全。
